Hub for all things security in aws(not just a clever name)

Centers on three points
- security checks
- centralization of findings
- monitoring and acting on findings

Checks are defined by 
- https://docs.aws.amazon.com/securityhub/latest/userguide/securityhub-standards-fsbp-controls.html
    - AWS foundational security best practices controls
- https://docs.aws.amazon.com/securityhub/latest/userguide/securityhub-pci-controls.html
    - PCI DSS
- https://docs.aws.amazon.com/securityhub/latest/userguide/securityhub-standards-cis.html
    - CIS AWS Foundations Benchmarks
